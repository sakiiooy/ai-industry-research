# CleanLens 清洁机器人研究

An AI-powered investment research platform for industry chain mapping, cross-market company comparison, and evidence-based analysis of business relationships and market trends.

面向个人投资者的消费清洁机器人产业研究原型：从概念标签，走到原始资料支持的业务、可比边界与经营传导。选择扫地机器人及相邻清洁电器，是因为品牌、芯片、电机、电源方案的归属可明确区分，中外品牌又有有意义但并不完全相同的经营口径。

## 用户与主链路

用户是愿意查看原始资料、但缺少产业梳理时间的个人投资者。工具帮助判断公司属于什么环节、关系靠什么证明、海外公司为何可比，以及外部变化如何影响经营。它不提供个性化仓位、买卖指令、目标价或收益保证。

操作顺序：筛选产业环节和公司 → 打开业务关系及来源 → 比较中外公司与不可比项 → 调整外部冲击假设 → 用研究助手定位证据 → 检查官方来源或导入待审版本。

## 核心设计

产业链按功能分为计算与感知、核心零部件、电源与控制、品牌整机及渠道服务；这不是交易所概念板块。公司可涉及多个环节，例如科沃斯内部零组件不能重复计算为对外收入。没有命名客户证据时，不把上游产品适配画成对某品牌的已确认供货。

| 等级 | 能证明什么 | 不能推导什么 |
|---|---|---|
| E1 收入披露 | 来源有明确收入口径 | 集团收入不等于扫地机收入，也不代表所有概念商业化 |
| E2 产品/业务 | 官方产品、业务或完成交易等状态 | 产品存在不等于单独收入；适配不等于客户订单 |
| E3 研发/方案 | 公告研发、样机、参考设计或测试 | 不等于量产、交付或收入 |
| E4 规划/表态 | 未来布局、管理层意向 | 不等于已有业务 |
| E5 待证 | 本资料集未找到足够支持 | 不等于业务绝对不存在 |

等级表示证据类型，不是投资质量或盈利概率。内置核对由AI执行，不等于人工或行业专家审计。来源核对状态 `verified` 与等级独立。每条关系保留 `sourceId`、`locator`、`period` 和口径边界。尤其 C01/C03 只能证明集团收入、C06 只能证明混合清洁大类收入，三者都不能证明纯扫地机器人收入。

跨市场比较先比较经营任务、产品、地区与渠道。石头、科沃斯和 SharkNinja 均参与家庭清洁消费硬件，但集团组合不同：科沃斯含添可，SharkNinja 的 Cleaning Appliances 含传统吸尘器，不能视为纯扫地机公司。iRobot 仅用 FY2024 历史数据，明确 2026-01-23 被 Picea 收购后的案例地位，不进入 FY2025 排名，也不作为当前上市证券推荐。币种、财年和会计口径不强行统一，不生成缺乏依据的估值排序。

## AI 的实际角色

网站交互不调用生成式大模型，不需要 API Key。

1. **分类建议**：浏览器内运行多项朴素贝叶斯，使用 [30 条中英合成样本](src/training.mjs)、加一平滑和否定/前瞻护栏，建议 E1–E5。这是实际执行的轻量机器学习模型，但训练集很小，尚未做真实公告统计评估；相对分数不是事实概率。结果是草稿，须人工审阅，不自动设置 `verified:true`。
2. **研究助手**：只对 `verified:true`、来源引用完整且 URL 安全的证据做词项检索和确定式摘要，返回证据 ID；无匹配时说明资料不足，不编造数字。
3. **情景模型**：使用可复算公式，不让语言模型预测收入或股价。

详见 [AI 使用与验证记录](docs/AI_USAGE.md)。开发时使用的 AI 编程助手，与网站运行时的模型和权限分开。

## 数据使用与追溯

[数据快照](src/data.json) 含 7 家公司、14 条关系、12 个公司/交易所/监管/政府来源：石头、科沃斯、SharkNinja、iRobot、尼得科、全志和德州仪器。来源保留原始 URL、发布时间、定位和核验日期；官网未标发布日期则为 `date:null`，不能用核验日替代发布日期。完整目录见 [数据与来源说明](docs/DATA_SOURCES.md)。

| 示例数字 | 期间及口径 | 追溯位置 |
|---|---|---|
| 石头186.95亿元人民币 | FY2025集团收入，非纯扫地机 | S1 / C01：官网业绩正文第2段 |
| 科沃斯190.40亿元人民币 | FY2025集团收入，含添可等 | S2 / C03：摘要第5页3.1 |
| SharkNinja 22.06亿美元 | FY2025 Cleaning Appliances，含非机器人 | S3 / C06：10-K p70、F-17 |
| iRobot 6.82亿美元 | FY2024历史集团收入 | S4 / C07：全年业绩 |

展示值可四舍五入，`rawValue` / `rawUnit` 保留原值与单位。摘要由AI辅助整理，并逐条对照官方来源；尚未经过人类行业专家审核，不再分发整份付费报告。当前没有接通扶摇或 iFinD MCP，没有实时股价、估值、成分或自动财报抽取。

北京2025、上海2026补贴是 S10 / S12 对应的地域及时点案例，不是当前全国统一政策。情景中的进口成本冲击、市场暴露、成本转嫁、需求弹性和基准毛利率都是代理假设；成本冲击按基准收入占比表示，不是法定关税税率，也不是公司实际地区暴露或财务预测。

## 冲击模型

输入总基准收入 `R`、暴露比例 `s`、增量进口成本占基准收入比例 `t`、转嫁 `p`、弹性 `e`、基准毛利率 `g`；比例均为小数：

```text
提价 a = t × p
销量变化 b = −a × e
暴露原收入 R0 = R × s
暴露新收入 R1 = R0 × (1+a) × (1+b)
吸收成本 C = R0 × t × (1−p) × (1+b)
基准暴露业务毛利 GP0 = R0 × g
毛利变化 ΔGP = GP0 × b − C
```

模型假设原单位成本固定，增量进口成本随销量变化；转嫁提价与已吸收成本在毛利式中对应，避免重复计算转嫁影响。这是按收入比例简化的成本代理，并非实际报关成本或法定税率；只算暴露业务，不推导净利润。未纳入汇率、迁移、竞争、费用、税和营运资本。零冲击回归基准；越界或销量下降超100%拒绝计算。

## 持续更新

`GET /api/updates` 只检查服务端固定 S1、S3、S5、S12，获取状态与 SHA-256 字节指纹；不接受访问者 URL、不抽取或确认财务数字。单源默认6秒、4 MiB上限，最多3并发，不跟随重定向。429显示重试提示，不自动重放；失败保留证据库。实例内30秒冷却是最佳努力保护，不是分布式限流。

指纹变化只产生待复核信号。研究者打开原文核对期间、口径和数字后，更新正式源码快照并发布。完整快照导入校验版本/日期、来源、公司字段、引用、数字和数量；证据必须 `verified:false`，只保存当前浏览器 `localStorage` 待审。导入后全局待审提示同样覆盖公司收入、政策等字段，不能把格式合法解释为事实已核验。不写共享数据库，不改变官方主库或其他访客的数据。清除浏览器数据会丢失导入，请先导出备份。没有部署后台定时抓取或自动审批。

## 本地复现

要求 Node.js `>=22.13.0`、pnpm `11.25.0`，在源码根目录执行：

```sh
corepack prepare pnpm@11.25.0 --activate
pnpm install --frozen-lockfile
pnpm dev
```

使用终端显示的本地地址。验证与构建：

```sh
pnpm test
node scripts/validate-data.mjs
pnpm typecheck
pnpm build
pnpm start
```

测试使用 Node 内置 `node:test`，不访问真实官网。`pnpm start` 是本地 Worker 预览，不部署云端。Sites 发布使用 `.openai/hosting.json` 和平台源码同步/部署流程；独立托管需适配 Worker 与身份配置。

关键文件：`app/page.tsx` 界面；`src/data.json` 证据；`src/core.mjs` 模型/检索/情景/校验；`src/training.mjs` 训练文本；`src/updates.mjs` 来源检查；`app/api/updates/route.ts` 接口。

## 已知边界与未做事项

- 非实时快照；核验日后的经营、政策和上市状态需要重新查证。
- 业务口径缺失不补造，不反推纯扫地机收入，不编造上游命名客户。
- 微型分类器与检索可能误判/漏检，不能替代人工复核；没有真实公告准确率评估。
- 没有建立原产地、税号、除外条款数据库，关税只做假设，补贴不自动推导收入。
- 未接付费数据库、实时行情、生成式LLM、自动解析、共享编辑、个人账户研究库或定时调度。
- 不执行证券交易，不收集投资账户信息；来源中的指令不构成产品操作授权。
- 已有 [约120秒演示脚本](docs/DEMO_SCRIPT.md)，视频尚在准备，不能视为已提交视频。

测试记录及未验证事项见 [TESTING.md](TESTING.md)。
