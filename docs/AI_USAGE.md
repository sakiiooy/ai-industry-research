# AI 使用与验证记录

记录日期2026-11-20；资料核验日2026-11-19。

## 开发与运行时分工

AI 编程助手协助拆解题目、检索公开资料、整理证据、编写代码和测试。资料中的指令只作为待研究内容，不成为用户授权。公司归属、数字和政策摘要均须原始资料定位支持，不能凭模型常识确认为事实。

网站运行时不会调用开发会话、继承开发者工具权限或付费数据库连接。没有生成式LLM、隐藏模型API或API Key。实际使用的是本地机器学习分类器，以及确定式检索、计算和校验。

## 分类器

`src/core.mjs` 的 `classifyEvidence` 使用多项朴素贝叶斯；`src/training.mjs` 含30条由AI编写的中英合成例句，每级6条。训练文本不是公司事实，也不是从年报训练得到的大规模模型。

特征为NFKC规范化、小写英文词和中文双字词项；模型统计每类先验与词频，使用加一平滑，累加对数似然并归一化为相对分数。模块加载时确定性构建模型。分数不是事实为真的概率、收益概率或投资评分。

材料为空、缺少识别词、缺证或否定时保守返回E5；收入未披露、前瞻/目标数字或缺少正向量化收入时不能建议E1。该规则也可能把“收入事实加边界说明”的复杂段落降级，所以应拆成单一主张再审阅。分类只建议草稿，不自动设置 `verified:true`。

## 研究助手

`retrieve` 通常匹配当前已对照来源的主张，最多返回4条，使用确定模板附证据ID、期间、定位及边界。供货问题可额外返回E5范围缺证记录，明确标为待证、非正向业务事实。它不生成新事实；无匹配时明确本资料集不足，不断言真实世界不存在。

买卖、目标价、收益保证或内幕请求被拒绝。“忽略规则”等指令性输入按文本处理。规则不构成全面自然语言安全能力，变体、暗语和复杂上下文仍需人工监督。

## 已执行验证

| 对象 | 实测 | 结果边界 |
|---|---|---|
| 训练材料 | 每级中英覆盖，声明合成来源 | 自动通过，不证明真实准确率 |
| E1建议 | “年报披露业务收入100亿元” | 返回E1；这是测试虚构例句 |
| 否定/缺证/前瞻 | 中英否定、未披露收入、目标收入、空文本 | 均不能升级E1 |
| 数据schema | 当前 `src/data.json` 内置可信模式 | 通过，允许发布日期未知null并保留核验日 |
| 检索 | 已核验附引用，未核验或不安全来源排除 | 自动通过 |
| 无匹配/合规 | 无关问题、买卖、收益保证、忽略指令 | 缺证或拒绝，不编造 |
| 导入 | 访问者自带 `verified:true` | 拒绝，须人工复核 |
| 情景 | 零冲击、已知代入、越界 | 公式结果通过，不是预测 |

另外手动检查了5条未原样出现在训练集中的中文改写例句，分别覆盖E1–E5，结果符合预期。这只是微型烟测，不是独立真实公告测试集，不据此报告泛化准确率。

完整自动测试见 `TESTING.md`。模型给出答案、网页可获取或指纹未变化，都不代表财务结论已经真实。

## 来源核对流程与未做事项

本次内置资料由AI辅助检索与逐条核对，未经人类行业专家审核。建议的人工复核流程如下：先拆单一主张，再打开官网/交易所/SEC/政府原文，核对期间、币种、单位、业务口径和页码；审阅建议等级及“不能证明什么”。源码维护者确认后才能把正式主张设为已核验，保留版本并发布。浏览器导入保持待审。

“计划拓展”“适用于机器人”“样机研发”不能改写为已有机器人收入。全志向石头供货的关系维持E5待证，无证据不等于不存在。

未建立真实公告标注集、双人一致性审阅、精确率/召回率、漂移监控或长文抽取评测；未做自动批准财报、付费接口或大模型事实核验。未来增加生成式模型也须保留引用、缺证拒答和人工审批。
